# AEGIS Production Readiness & Operations Guide

## Service Level Objectives (SLOs)
- **API Availability**: 99.95% monthly uptime.
- **SOS Incident Persistence**: < 100ms durable database commit (P99).
- **10km Responder Matching**: < 2000ms from SOS creation to candidate broadcast.
- **Weather Data Freshness**: Max age < 30 minutes for observations, < 6 hours for numerical forecast runs.
