# AEGIS Dual Map GIS Architecture

## Map 1: Weather & Hazard Intelligence Map
- **Purpose**: "What is happening geographically?"
- **Layers**: Temperature, Precipitation, Wind Gusts, AQI, Cyclone Tracks, Flood Polygons, Lightning Strikes, Safe Shelters.

## Map 2: Tactical SOS Command Map
- **Purpose**: "Who needs help right now?"
- **Markers**: High-visibility blinking red markers, time elapsed, masked contact info, battery %, assigned responder ETA.
